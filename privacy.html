Política de Privacidad de Ninja Code Pro

Última actualización: Noviembre de 2026

1. Información que recopilamos

Ninja Code Pro almacena localmente en el navegador del usuario las preferencias de configuración, listas de códigos generados y el historial de lotes mediante la API de almacenamiento de Chrome. Para la activación de licencias, pruebas gratuitas y soporte técnico, se registra un identificador de dispositivo anónimo y el nombre o alias proporcionado voluntariamente por el usuario.

2. Uso de la información

Los datos recopilados se utilizan exclusivamente para:

  • Proporcionar las funciones de asistencia de autocompletado, temporizadores y exportación de archivos de texto (.txt).
  • Validar el estado de la suscripción o prueba gratuita del usuario en nuestro servidor seguro (Supabase).
  • Atender consultas enviadas voluntariamente por el usuario a través del buzón de soporte integrado.

3. Compartición de datos con terceros

No vendemos, alquilamos ni transferimos datos personales o de navegación a terceros. Los pagos de suscripciones son procesados directamente de forma segura por Stripe.

4. Contacto

Para cualquier consulta sobre esta política de privacidad o soporte técnico, puedes contactarnos en: joostoficial@gmail.com
